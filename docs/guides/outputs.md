# Outputs Guide

GhostStream outputs encoded or raw video to virtual camera, files, and streaming protocols.

## Virtual Camera

The virtual camera output creates a PipeWire video source for local applications.

## File Recording

File output supports common containers such as MKV, MP4, WebM, and TS through FFmpeg.

## Streaming

RTMP targets common services such as Twitch and YouTube. SRT is available for lower-latency custom transport workflows.
