# API Reference

## Primary Modules

| Module | Purpose |
|--------|---------|
| `capture` | Screen, DMA-BUF, webcam, and audio capture |
| `processing` | Scaling, colorspace conversion, HDR, and background processing |
| `encode` | Hardware and software encoder backends |
| `output` | Virtual camera, file, RTMP, and SRT output |
| `config` | Presets and encoder configuration |

Generate complete API documentation locally:

```bash
cargo doc --open
```
